# Project Contract

Every version must complete encoded image bytes -> official OmniParser icon_detect_v3 -> raw proposals -> anonymous candidates -> Temporal Focus -> focused bbox or legal abstention. Historical candidates, fixtures, VLM/OCR semantics and GT inference are forbidden.

Every version must contain project-owned executable code, run outside the repository, have zero repository imports and symlinks, provide runner/config/schema/requirements/tests, pass self-test and live Omni-to-Focus smoke, and not depend on a prior version folder.
